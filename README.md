# Director Page V23

มีเฉพาะหน้า Director ตามที่ขอ

Flow:
1. เปิดหน้า → “สวัสดี ผอ.สุทธานนท์”
2. ด้านล่างแสดงรูป ผอ.ถือถุงผ้า
3. กด “พรีออเดอร์กระเป๋า”
4. หน้าเลือกจำนวน 1–10 หรือ 100 ใบ
5. หน้าชำระเงิน + แนบสลิป
6. หน้าตรวจสอบข้อมูล
7. กดยืนยันส่ง

รูป ผอ.:
- ให้วางรูปจริงไว้ที่ `img/director-bag.png`
- ถ้ายังไม่มี ระบบจะแสดง placeholder `img/director-placeholder.svg`

QR:
- ใช้ `qr/qr-1.png` ถึง `qr/qr-10.png`
- จำนวน 100 ใบใช้ `qr/qr-100.png`
- ถ้าไม่มี จะ fallback เป็น `payment-qr.svg`

หมายเหตุ:
ไฟล์นี้ออกแบบให้วางทับ/เพิ่มเข้าโปรเจกต์เดิม โดยใช้ `firebase-config.js` เดิม
